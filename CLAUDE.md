# CLAUDE.md

## Project overview

Static HTML book generated from a Dec 2022 Twitter export. The book is titled "vgr: The Twitter Years, 2007–22" by Venkatesh Rao. It contains 102 chapters: a "Noteworthy Singletons" compendium of curated individual tweets, plus 101 thread chapters ordered chronologically.

## Build commands

```bash
# Standard rebuild (run both, in this order):
python3 data/generate_compendium_chapter.py
python3 data/generate_book_html_with_titles.py

# Preview:
cd book && python3 -m http.server 8000
```

The book generator clears and regenerates all `book/chapters/chapter_*.html` files each run. It also regenerates cover, title, ToC, and preface pages. It patches navigation into the compendium page (generated separately).

## Architecture: three layers

1. **Data normalization + cleanup** — normalizing raw tweets, building threads, applying patches/ops
2. **Content generation** — `generate_compendium_chapter.py` and the thread chapter rendering in `generate_book_html_with_titles.py`
3. **Book scaffolding + navigation** — page shells, nav bars, ToC, frontmatter rendering (all in `generate_book_html_with_titles.py`)

Shared tweet text rendering lives in `data/tweet_text_cleanup.py` (used by both generators).

## Key files

| File | Role | Editable? |
|------|------|-----------|
| `data/frontmatter/*.html` | Cover, title, preface fragments | Hand-edited, never auto-overwritten |
| `data/chapter_titles.json` | Chapter title overrides | Hand-edited |
| `data/url_overrides.json` | Broken/hijacked URL replacements | Hand-edited |
| `data/selection_final_clean.json` | Selected thread IDs + compendium tweet IDs | Pipeline output |
| `data/url_titles.json` | Cached page titles for URLs | Generated by `fetch_url_titles.py` |
| `book/style.css` | All styling | Hand-edited, never auto-overwritten |
| `book/**/*.html` | Generated output | Regenerated each build |

## Constraints

- **Python 3.9 compatibility**: No backslashes inside f-string expressions (allowed only in Python 3.12+). Extract to variables first.
- **`book/style.css` is sacred**: Never overwrite it. Only append/edit specific rules.
- **Frontmatter fragments are sacred**: Read from `data/frontmatter/`, never auto-rewritten. Generators create defaults only if files are missing.
- **Media only for selected content**: `copy_media_to_book.py` filters to selected threads + compendium tweets only.
- **Chapter numbering**: Compendium is chapter 1; threads start at 2, ordered chronologically.
- **Reading order**: Cover → Title → ToC → Preface → Noteworthy Singletons → Thread Chapters.

## Tweet text rendering pipeline (tweet_text_cleanup.py)

1. Unescape HTML entities (`&gt;` → `>`)
2. Strip media t.co URLs (media rendered separately as embeds)
3. Replace entity URLs with placeholders
4. Escape remaining text for HTML
5. Replace placeholders with rendered links:
   - Self-tweet URLs: stripped from text (content shown as quote box instead)
   - Other-people tweet URLs: rendered as "tweet" + superscript endnote `[N]`
   - Regular URLs: anchor text from fallback chain (url_overrides title → fetched title → display_url → "link")
6. Apply `*bold*` and `_italics_` markdown
7. Convert newlines to `<br>`

## URL systems

- **url_titles.json**: Cached page titles, fetched by `fetch_url_titles.py`. ~237 entries. Supports `--retry` for failed entries.
- **url_overrides.json**: Manual replacements for hijacked/broken URLs. Structure: `{overrides: [{original_url, replacement_url, title, reason}]}`.
- **Endnotes**: External tweet links get per-chapter endnotes at chapter bottom showing `@handle — full URL`.
